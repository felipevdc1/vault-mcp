# vault-mcp

> Intelligent skill resolver for Claude Code — discover, compose, and evolve your AI toolkit.

by **Felipe Vieira Domingues Carneiro** · [@o.felipecarneiro](https://instagram.com/o.felipecarneiro)

## What is vault-mcp?

An MCP (Model Context Protocol) server that transforms how developers use skills in Claude Code. Instead of loading hundreds of skills and hoping for the best, vault **automatically resolves** which skill to use for each task — and grows smarter with use.

## Features

- **vault_resolve** — Agents automatically find relevant skills before executing tasks
- **vault_search** — Explore your entire skill ecosystem
- **Manifests** — Rich, structured metadata for every skill
- **Recipes** — Pre-defined skill combinations for common tasks
- **Forge** — Skills grow organically from agent usage
- **Project Profiles** — Auto-load relevant skills per project
- **Dashboard** — Visual overview of your skill ecosystem
- **Integrations** — Auto-detects MemPalace, codebase-memory-mcp

## Quick Start

```bash
npx vault-mcp init
```
